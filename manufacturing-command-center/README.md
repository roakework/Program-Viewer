# Manufacturing Command Center

Standalone executive operating hub for a CNC manufacturing business.

## Open the application

Download `manufacturing-command-center/index.html` and open it in Chrome or Edge. No installation or server is required.

## Included

- Executive command board with priorities, opportunity, scorecard health, and overdue actions
- Improvement initiative tracking with ownership, deadlines, progress, and annual value
- Editable KPI scorecard
- Pricing and margin review register
- 6061 aluminum, yield, purchasing, and scrap opportunity tracking
- Machine-group utilization and downtime tracking
- Kanban action board
- Browser-based persistence plus JSON backup and restore
- Responsive desktop and mobile layouts

## Data behavior

All operating data is stored in the browser's local storage. Use **Export backup** regularly. Opening the file in a different browser or on another computer starts a separate data set unless a backup is imported.
